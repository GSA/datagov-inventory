# Inventory 2.0

## Overview
Data.gov's [Inventory app](https://inventory.data.gov/) is a tool for federal agencies to create and publish metadata catalogs.

Inventory 2.0 is a rewrite of the existing app, targeting the new DCAT 3.0 standard and no longer based on CKAN. This repository will eventually replace https://github.com/GSA/inventory-app/.

This repository belongs to the [Data.gov project](https://github.com/GSA/data.gov).
