Help

About this alpha

This is an early test version of the Data.gov inventory editor. It is for trying out the editing model and giving feedback. It may change, and it may have problems.

  1. Open

    Import a DCAT-US 3.0 JSON file, paste JSON, import from a web address, or start from scratch. Files with problems still open.

  2. Edit

    Browse the catalog tree and edit any object. One form is open at a time. In a field that holds another object, pick an existing one or choose Create new: the new object’s form replaces the current one, and Back takes you to where you were. Changes save as you type.

  3. Check

    The advisory check runs after every change. Problems are marked in the tree and listed under Check catalog. Nothing is blocked.

  4. Export

    Download the catalog as a DCAT-US 3.0 JSON file, even if it still has problems.

Where your data lives

  • Your working copy is kept in this browser’s own storage, on this device only.
  • Files are read in the browser. Nothing is uploaded and nothing is sent anywhere.
  • It is not backed up. Clearing this browser’s site data deletes it. Export to keep a copy.
  • On a shared computer, use Clear my data when you finish.

Your changes save as you type, about half a second after you stop. Moving between forms never loses anything. When you come back, the start page offers to continue with your working copy, download it, or discard it.

The status next to the working copy name shows “Saving…”, “Saved [time]”, or “Not saved”.

The advisory check

This is an advisory check, not the official Data.gov validator. It compares your catalog with the DCAT-US 3.0 schema (GSA/dcat-us, version of October 7, 2026, commit 4996591), in your browser. Passing it does not mean Data.gov will accept your catalog.

Known limits

  • DCAT-US 3.0 JSON only. data.json (DCAT-US 1.1) files are refused; the alpha does not translate 1.1. The current inventory can export a catalog as DCAT-US 3.0.
  • One working copy at a time. Every object has its own address, so you can open objects in new tabs or share a link with yourself; if another tab changes the catalog, the editor asks you to reload.
  • Files up to 50 MB. Catalogs of up to [number from the responsiveness check, #29] datasets stay responsive.
  • Tested in [browsers from #29 and #30].

Using the catalog tree with a keyboard

  • Tab moves into the tree once. Up and Down arrows move between items.
  • Right arrow opens an item, or moves to its first child. Left arrow closes it, or moves to its parent.
  • Home and End go to the first and last item. Typing a letter jumps to the next item starting with it.
  • Enter opens the object in the form. Moving through the tree does not open objects by itself.

Parts built for this editor

Most of the editor uses the U.S. Web Design System as is. These parts were built for it and are tested separately (#30): the catalog tree (an ARIA treeview), the two-pane layout, the linked-object rows, the inline “Add an existing …” combo box, the rows of fields that hold several values, and the confirmation dialog.
