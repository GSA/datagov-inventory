Screen map: Data.gov Inventory editor alpha mockups

Clickable USWDS mockups for the browser-only editor alpha (GSA/datagov-inventory#15). Nothing here works for real: no file is read, stored, or sent.

This page and the dashed “Mockup only” boxes at the bottom of screens are not part of the product. Use them to jump to any screen or state. All data is fictional (Department of Example Affairs). See README.md and SPEC.md in this folder for the flows, the spec, and open questions.

Click-through flows

  1. First visit, open a file: start.html → start.html?state=progress → workspace.html?state=loaded → editor/catalog.html → editor/dataset.html
  2. Start a blank catalog: start.html → editor/catalog.html?state=blank → editor/dataset.html?state=create
  3. Returning user: restore.html → workspace.html → editor/catalog.html
  4. Reuse or create a contact: editor/dataset.html → editor/dataset.html?state=select → editor/dataset.html?state=create → editor/dataset.html?state=create-nested
  5. Edit a shared contact: editor/dataset.html → editor/contact.html?from=d5 → editor/dataset.html?state=copy-made
  6. Remove and undo: editor/dataset.html?state=removed-link → editor/contact.html?state=delete-shared → editor/contact.html?state=deleted → editor/object.html?state=delete-unused
  7. Check and fix: check.html?state=running → check.html → editor/dataset-errors.html?state=errors → check.html?state=stale
  8. Export: export.html → export.html?state=done → export.html?state=loop-error
  9. Large catalog: workspace.html?state=large → editor/list.html?state=large → editor/dataset.html
  10. Clear my data, storage problems, second tab: workspace.html?state=clear-confirm → start.html?state=cleared → editor/dataset.html?state=storage-failed → in-use.html
