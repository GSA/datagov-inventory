Screens and routes

The editor is now one page, editor.html, that switches views by its hash route. Load a catalog first: routes below open in your current working copy.

Editor routes

With the 9-dataset sample loaded, these ids exist. Ids are made when a catalog is loaded, so they differ for other catalogs.

RouteView
#/Catalog form
#/dataset/<id>Dataset form, reached from the catalog
#/dataset/<id>/distribution/<id>Distribution form, under its dataset. Each id must link to the next one.
#/dataset/<id>/distribution/<id>/access-restriction/<id>Three levels deep: Catalog › Dataset › Distribution › Access restriction
#/contact/<id>Any object by id. The editor finds where it lives in the tree and opens that path; an object that is not linked anywhere opens under “Not linked anywhere”.
…?field=modifiedOpen the object and move focus to one field (used by the check results).
#/type/dataset, #/type/contact, …By type: every object of a class, A to Z, 50 per page, with New, Edit and Delete. ?page=2&q=help pages and filters.
#/checkAdvisory check results (always current: the check runs after every edit)
#/exportExport: problems first, Review problems, Download anyway. Downloads a real JSON file made in the browser.

Flows to click through

  1. Load: Start → “Load the 9-dataset sample” → the editor opens on the catalog with a load summary.
  2. Edit a dataset: tree → Grants to Local Partners → type in Title. The tree label changes as you type; the status goes Saving… then Saved.
  3. Create, three levels deep: Regional Bridge Condition Ratings → Dataset distribution → Create new distribution → the form is replaced by “Unnamed distribution”, linked to the dataset and already in the tree → Access restriction → Create new access restriction → fill in Restriction status → Back to the distribution → Back to the dataset. Everything typed is kept.
  4. Pick an existing object: any dataset → Contact point → “Add an existing contact” → type “help” → choose OSS Data Help Desk.
  5. By type: By type → Contacts → the trash icon on a row → “referenced in N places” → Delete.
  6. Check and export: Check catalog → a problem → the field. Export → Review problems or Download anyway.
  7. Deep link: copy the address of any form and open it in a new tab.
  8. Scale: Start → “Load a generated catalog with 2,000 datasets” → filter the tree.
